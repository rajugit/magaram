# Tamil editorial acceptance

Use this checklist for public copy and newsroom workflow acceptance, not as evidence that a story has already been verified.

| Area            | Required behavior                                                                                              |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| Locality        | Accurate Tamil town/district names; distinguish event location from the source's location                      |
| Time            | Event date and publication date are distinguishable; reader-facing dates use India time                        |
| Sources         | Material claims have traceable sources; uncertain/disputed claims are attributed, not stated as settled facts  |
| Approval        | Author cannot independently approve their own publication; changes follow the established review rules         |
| Corrections     | Published corrections state what changed and why, with the correction date                                     |
| AI              | Generated text is a saved proposal, reviewed against sources; no invented quotations or autonomous publication |
| Public privacy  | Drafts, source notes, private identities and enquiry contact details are excluded from public responses        |
| Sponsorship     | Paid material has a clear reader-visible label; payment cannot bypass editorial review                         |
| Directory       | Business verification is explained without implying a quality guarantee or newsroom endorsement                |
| Offers          | Real terms, exclusions and valid dates; future/expired/unapproved offers cannot be presented as current        |
| Consent         | Named purpose and business are clear; contact consent does not imply marketing subscription                    |
| Tamil usability | Headings, labels, errors, keyboard focus, small-screen navigation and paragraph wrapping remain readable       |

An editor must resolve missing reporting evidence before publication. A product test can prove the approval gate works; it cannot prove the truth of a story.
