# Magaram Media brand

The Tamil brand name is **மகரம் மீடியா**. Use **மகரம்** for the short name.

The user-supplied logo is preserved unchanged in `apps/web/public/brand/magaram-logo.png` (180 × 180 pixels). The web header and browser icon use this asset.

The web shell uses a palette matched to the supplied artwork:

| Token    | Color     | Use                           |
| -------- | --------- | ----------------------------- |
| Orange   | `#FF9E32` | Accent bands and highlights   |
| Coral    | `#D95367` | Decorative borders            |
| Burgundy | `#9C3B50` | Wordmark and section headings |
| Ink      | `#44212B` | Main text                     |
| Muted    | `#73535B` | Supporting text               |
| Cream    | `#FFF8F0` | Page and card backgrounds     |

Tokens are defined in `apps/web/app/globals.css`. Bright orange and coral are reserved for decoration; dark ink and burgundy provide readable text on light backgrounds. The original white logo background is retained. A higher-resolution original will be needed for large print or hero placements.
